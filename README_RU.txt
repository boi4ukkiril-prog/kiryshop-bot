KiryShop — Yupoo + WeCatalog
Версия: YUPOO-WECATALOG-2026-11-12
Python 3.10 или новее.

УСТАНОВКА
1. Сохрани копию своего прежнего bot.py.
2. Замени bot.py файлом из этого архива.
3. Установи зависимости в окружении проекта:
   python3 -m pip install -r requirements.txt
4. Оставь прежние переменные окружения BOT_TOKEN, GROUP_ID, DATABASE_URL,
   ALLOWED_USER_ID (если задан). Их значений в этом архиве нет.
   Используется тот же PostgreSQL: темы и история Yupoo сохраняются.
5. Перезапусти бота тем способом, которым он работал раньше.
   Для локального запуска при уже заданных переменных:
   python3 bot.py
   Код читает переменные окружения; сам по себе файл .env не загружает.
6. Запусти только один экземпляр бота.

ПЕРВАЯ ПРОВЕРКА
Отправь своему боту:
/version
Ожидается: KiryShop build: YUPOO-WECATALOG-2026-11-12

Если тема Shoes ещё не зарегистрирована, отправь внутри этой темы группы:
/register Shoes
Бот должен состоять в группе и иметь возможность отправлять фото в тему.

Проверь поставщика БЕЗ публикации:
/check Shoes https://topdreamer.wecatalog.cn/t/SlobuEh 5

Затем опубликуй 5 товаров:
/import Shoes https://topdreamer.wecatalog.cn/t/SlobuEh 5

Остановка:
/stop
Остановка произойдёт после текущей загрузки каталога или отправки товара.
Уже опубликованные сообщения остаются в группе.

КАК РАБОТАЕТ ВЫБОРКА
Число 5 означает пять последних подходящих товаров в каталоге, а не пять
обязательно новых постов. Уже опубликованные товары пропускаются.
Чтобы просмотреть более широкую выборку, увеличь число, например до 20.
Диапазон: 1–1000, максимум 100 страниц за один запрос.
По умолчанию для WeCatalog выбирается 5 товаров.
Внутри выбранной партии более старые товары отправляются первыми.
Для всей подборки используется ЯВНО указанная тема: Shoes, Bag и т.д.
Автоматической классификации смешанного магазина нет.

WeCatalog: используется гостевой сеанс открытого каталога, без логина.
Поддержаны ссылки /t/... с переходом на /weshop/store/... и страницы
/weshop/goods_list/...; отдельные карточки товаров пока не поддержаны.
Закреплённые записи (включая закреплённые товары), записи без фото и
записи с запретом скачивания пропускаются. Это отсеивает объявления
поставщика, но не является полноценным распознаванием товара на фото.

Yupoo: ссылку на раздел можно отправлять как раньше, без команды.
С явной темой и лимитом:
/import Protocol Index https://АДРЕС_РАЗДЕЛА_YUPOO 5
Без лимита обычная ссылка раздела Yupoo обрабатывается как раньше,
до 100 страниц. /topics показывает сохранённый список категорий.

ФОРМАТ ПОСТА
Одна основная фотография и подпись:
📩 Price and order in private messages
Название, китайское описание, цена и ссылка поставщика не публикуются.
Как в присланной версии, водяной знак не рисуется: переменная
WATERMARK_TEXT оставлена для совместимости.

ИСТОРИЯ ПУБЛИКАЦИЙ
Старые ID Yupoo не меняются. ID WeCatalog имеют префикс wc: и включают
поставщика и товар. Повторная отправка ссылки не публикует сохранённые
товары снова, в том числе при выборе другой темы.
/reset Shoes очищает историю этой категории, а не сообщения группы.
После reset повторы снова могут публиковаться. Для обновления кода reset
НЕ нужен.
Telegram и PostgreSQL не имеют общей транзакции: если процесс аварийно
остановится после отправки фото, но до сохранения ID, возможен повтор.
При обнаруженной ошибке сохранения истории текущий импорт прекращается.

ПРОВЕРЕНО 12 НОЯБРЯ 2026
— Открытие указанного магазина без учётных данных.
— Получение 35 уникальных товаров с переходом между страницами.
— Скачивание главного фото товара.
— Разбор команд и алиасов, фильтрация закреплённых записей,
  отдельные ID поставщиков, резервное скачивание фото.
— На имитации Telegram/БД: пропуск дублей, отсутствие публикации
  при /check, прекращение импорта при ошибке истории.
Реальная публикация в твою группу и доступ к твоей БД здесь не проверялись:
для этого нужны существующее окружение и запущенный бот.
Фильтры конкретных разделов WeCatalog отдельно не проверялись на живом
разделе; основной проверенный сценарий — указанная ссылка магазина.
Сайт использует внутренние запросы: при изменении WeCatalog может
потребоваться обновление адаптера. Фонового мониторинга новых товаров
в этой версии нет: импорт запускается сообщением или командой.
