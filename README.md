# KiryShop Bot — 3 разные фотографии без размерной сетки

Исправлено:
- бот публикует максимум 3 разные фотографии товара;
- одинаковые URL удаляются;
- одинаковые файлы удаляются по SHA-256;
- визуально одинаковые уменьшенные копии удаляются по perceptual hash;
- пропускаются отдельные таблицы размеров;
- пропускаются объединённые изображения, где таблица размеров встроена между фотографиями товара;
- маленькие служебные изображения пропускаются;
- если подходящих фотографий меньше трёх, бот отправляет только найденные;
- подпись остаётся: 📩 Price and order in private messages.
