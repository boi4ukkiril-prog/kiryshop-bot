# KiryShop Bot v2

Бот загружает целые разделы Yupoo в темы Telegram-группы.

## Возможности

- массовая загрузка товаров из раздела Yupoo;
- публикация в нужную тему Telegram;
- до 4 фото на товар;
- перевод названия на английский;
- водяной знак;
- защита от повторов через PostgreSQL;
- итоговый отчёт по загрузке.

## Railway Variables

Добавьте в сервис `kiryshop-bot`:

- `BOT_TOKEN`
- `GROUP_ID`
- `DATABASE_URL`
- `WATERMARK_TEXT`
- `ALLOWED_USER_ID`

## Регистрация темы

Создайте тему в группе и внутри неё отправьте:

`/register Shoes`

Список допустимых категорий:

`/topics`

## Использование

После регистрации темы отправьте боту ссылку на целый раздел Yupoo.
