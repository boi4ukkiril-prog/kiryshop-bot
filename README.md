# KiryShop Bot v2

## Возможности

- импорт целого раздела Yupoo;
- публикация в темы Telegram-группы;
- до 4 фото;
- перевод названий на английский;
- водяной знак;
- защита от повторов через PostgreSQL;
- отчёт после загрузки.

## Railway variables

- BOT_TOKEN
- GROUP_ID
- DATABASE_URL
- WATERMARK_TEXT
- ALLOWED_USER_ID

## Регистрация темы

Создай тему Telegram, открой её и отправь:

`/register Shoes`

Список допустимых названий:

`/topics`

## Использование

После регистрации нужной темы отправь боту ссылку на целый раздел Yupoo.
