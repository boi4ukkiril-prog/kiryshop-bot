# KiryShop Yupoo → Telegram Bot

Бот принимает ссылку на один альбом Yupoo, берет до 4 фотографий, переводит название на английский, наносит водяной знак и публикует товар в Telegram-канал.

## Переменные Railway

Добавьте в Railway → Variables:

- `BOT_TOKEN` — новый токен от BotFather.
- `CHANNEL_ID` — username канала, например `@kiryshop`.
- `WATERMARK_TEXT` — текст водяного знака.
- `ALLOWED_USER_ID` — необязательно. Ваш цифровой Telegram ID, чтобы бот принимал ссылки только от вас.

## Запуск

Railway автоматически установит зависимости из `requirements.txt` и запустит команду из `Procfile`.

## Использование

Отправьте боту ссылку на конкретный альбом Yupoo. Бот опубликует до 4 фото и подпись:

Название на английском

📩 Message for price and order

## Важно

Yupoo иногда меняет структуру страниц. Если конкретный поставщик закрывает альбом паролем или блокирует автоматическую загрузку, парсер потребуется адаптировать.
